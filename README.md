# Pierwsze Soboty

Aplikacja mobilna Flutter: nabożeństwo pierwszych sobót miesiąca (Fatima).

- Ekrany: Strona główna, Warunki nabożeństwa, Kalendarz/Ścieżka postępu, Informacje
- Funkcje: lokalne powiadomienia, zapis postępu (SharedPreferences), animacje, tryb offline
- Język: polski (PL)

## Uruchomienie lokalne

Wymagany Flutter (channel stable).

```bash
flutter pub get
flutter run
```

## Web (GitHub Pages)

Workflow buduje `flutter build web` i publikuje do gałęzi `gh-pages`. W ustawieniach repo ustaw Pages na `gh-pages`/root.
